## What changed

The Wick RTX 4090 trained two native 13,336-byte UORSTT01 states from the same #4288 parent. Both saw the same 64 common far pairs and 64 replacement pairs. One arm received the far versions of the replacement pairs. The other received their matched near versions. Each arm had 256 prompts, 512 eligible signed edges and eight simultaneous integer updates. The original governors, token addresses, native proposals, joint ranker, two banks of eight 32-coordinate i16 centers, tokenizer and writer stayed on the same architecture. Only transport center values could change. The device recorded the separate vote sums for each distance without using the distance label to choose a center or change the serving path. The far clauses also add words and structure between the verb and noun. This compares two curricula. It does not isolate token distance from wording. ## Still open

Test protection **during** the integer update. Start with the same parent and enumerate a bounded set of the near/far-voted coordinate or center changes on TRAIN. Keep moves only if the unchanged joint reader still wins all protected near pairs and the shared far loss falls. Record how many nonzero moves are feasible, which protected rival blocks the first rejected move, and whether any accepted change converts a full far pair. Use the same state size and an unconstrained update with the same search budget as a control. Freeze the candidate before a new held panel. This distinguishes a harmful pooled step from failure to find a useful move within the existing representation. The current eight pooled sweeps test only that trajectory. [Grounded-reply milestone](https://github.com/UOR-Foundation/uor-r4/issues/2030)

## Plain summary

Adding near examples helped the mixed learner find more near training pairs. Some of the original good sources changed on every update. A check applied after training could reject those states and recover the parent, but it produced no new state that preserved both behaviors. The first observed regression is an original noun losing to a different source before the writer runs.
