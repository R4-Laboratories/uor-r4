# Addressed source ranking on Wick

The historical #4283 source exporter uses its unchanged `Query::scope_candidates` and `Query::scope_triples` against the fixed pooled D11's reader and roots. Preparation independently re-encodes the user frames, checks the supplied EOS-terminated history and reconstructs every proposed BPE span from its exact bytes. It verifies that the fit's pooled scope and action banks equal the serialized D11 banks. Gold, exact exchange and both orientations of the same-spelling neutral competitor must occur in the proposer output. Preparation makes no bank-distance or rank calls.

`geometry.bin` contains the ordered proposal points as 96 little-endian i16 words, their raw current-user byte spans and absolute prompt BPE spans, then the original local u32 tuple indices. ABI 2 gives each arm its own side-information packet. Each link arm receives the two signed governor addresses in the same order as governor-only, plus an independent unordered list of unsigned governor-to-noun edges. The ranker resolves each signed source by an exact match of both governor span bounds before checking the noun address. An unmatched governor makes every proposal ineligible. Exchanging the two noun endpoints preserves both signs and governor sites. Every primary arm keeps the original heading candidates. Held labels live in `labels.json` and the GPU accepts no labels argument.

The SM89 rank receipt records three nearest Manhattan costs at every point, the integer score and eligibility or governor gap at every candidate, and the best winner and tie count. An eligible candidate has secondary bank cost equal to the sum of its three signed head costs. Governor-only compares the sum of two half-open BPE interval gaps before comparing that cost. Tied minima emit no selected address. The Rust oracle independently replays every primary-arm field against the exact native bank operator. After the join it restricts those same verified candidate costs to the gold heading for a conditional diagnostic.

## Wick

Stage these source files under the new study root. Run `run-wick.sh build v2` and `run-wick.sh finite v2 v2` for the hand-checked device fixture. It changes just one governor-edge bound with both signed keys and noun spans fixed and requires abstention. Flipping the signed keys while keeping the edges fixed must give exactly the exchanged-arm receipt. The wrapper compiles against the sealed #4283 exporter source and the established fixed-bank SM89 implementation, and uses the existing Wick GPU lease. Preparation is `run-wick.sh prepare v2 v2 FROZEN_REFERENCE`. After independent FIT and release, `run-wick.sh score v2 v2 PREPARED_DIR RELEASED_MANIFEST RELEASED_MANIFEST_SHA256` writes the five raw arm ranks, a second identical full run, noun and link packet permutations, `endpoints.jsonl`, and the Rust differential receipt. The release ledger must bind the build, prepared inputs and fixture. The exact history is regenerated by the ordinary client stage if the source gate passes.
