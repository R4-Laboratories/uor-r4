# Does a source-addressed governor link recover the original noun?

Lab: codex

References [grounded reply training](../../../../roadmap/items/m2-train-grounded-replies.md) and [M2](https://github.com/UOR-Foundation/uor-r4/issues/2030). The earlier reader sometimes received identical points for the two assignments of a distant governing verb. This intervention tests the value of making source addresses available explicitly. It includes no fitting.

**Panel.** Enroll 128 opposed pairs on four new wording families, 256 conversations. Each pair exchanges which instruction authorizes the same final noun. Cross a short and a long verb distance within every family, on the original signed BPE tape. Both members keep first history, facts, requested reply, noun order and neutral same-word distractor fixed. Cross placement/order and the requested first fact. For every prompt independently prove that the current user's two original nouns, the two governor spans, the extra same-spelling noun and the later reference are distinct as applicable, and that the exact, exchanged and neutral-rival source tuples exist in the shipping proposal set. Preserve all qualifying generated prompts. A generator or proposer incompatibility during the pre-score fixture is an instrument finding. Freeze input identities and every arm before collecting any held winners.

**Five reads.** Every arm sees the original native proposal set and fixed 96-coordinate i16 prototype banks. Native minimizes the same three nearest Manhattan distances as the fixed D11. Governor-only receives affirmative and excluded verb spans, ranks earlier noun assignments first by summed unsigned gaps between half-open BPE spans and then by native cost, and searches the original headings. Overlap or adjacency gives a zero gap. Nouns-only receives the two true earlier noun spans without their order, searches both assignments and all headings, and uses native cost. An explicit link arm attaches each signed governor to one noun, constrains the two earlier tuple positions to these linked endpoints, and ranks remaining headings using native cost. Exchange only the two attachment targets in its negative control. Correct and exchanged links carry the same verb sites and noun locations. Their orientations are supplied assistance. Neither receives the answer heading, its token, the gold tuple ordinal or the desired output action. A tie between different best tuples abstains. Grade against the three exact original byte and BPE spans. Report the earlier-noun assignment and a diagnostic with only the gold heading admitted separately from the full-proposer result.

**Source gate.** Count one strict pair win only when both opposite prompts have the unique, exact original triple. Over the 128 enrolled pairs the correct-link arm must gain at least eight net strict wins over native and at least eight over exchanged links. It must beat native in both distance strata and may lose no wording family's strict pair count versus native. This is a fixed-panel causal diagnostic with the previous eight-pair detection threshold. Report all partial arms even if one ties or beats the correct-link arm. A pass establishes sufficiency of the supplied information under this reader. Recovery from governor-only or nouns-only quantifies how much of that assistance was actually needed. Report per-arm counts, both distance strata, complete gains and losses, single wins, ties, same-noun captures and wrong later references. Failures of provenance, GPU/oracle differential, address authenticity or controls are instrument failures to repair before interpretation.

**Instrument repair before held scoring.** Build v1 could attach a noun from an edge's role tag while ignoring its governor address. Its finite measurements are retained on Wick. Build v2 carries the two signed governor sites separately from an unordered pair of unsigned governor-address to noun-address edges. Both the device and the independent oracle must find each edge by its original governor span. Moving a governor address on one edge while keeping both noun targets and both signed query sites fixed must yield zero eligible tuples. Reversing edge order must preserve the picks and swapping only its noun targets must exchange the attachment. The enrolled prompts and source gate stay fixed. No held selections were observed from build v1.

**Candidate counts before scoring.** The full proposer has 52–384 tuples per prompt and can offer up to five distinct later references. Independent enumeration without scoring found exactly one eligible tuple on every prompt after either supplied link filter. Both choices of polarity remain available with unordered nouns, but both share one later reference. Correct/exchanged links are therefore positive and negative controls for executing the supplied attachment. The source gate tests their improvement over native. These two controls cannot establish that the bank learned to identify the heading. The governor-only and native arms still search the full proposal set, and the nouns-only arm must decide between two orientations.

**Conditional ordinary run.** Only after a gate pass, capture the actual ordinary client on precisely these conversations for native and the four interventions. Use the GPU winner's authored spans, rechecked against the current user bytes, with the first role and ending supplied identically. Re-generate and match the real first assistant history. Require an explicit equivalent abstention path when there is no unique selection. Verify the client reads the selected addresses or corresponding unresolved state. Capture the same-prompt stock for exclusions. Report exact visible replies through EOS, both replies exact, fact copy from the original on TAKE, explicit DEFER on exclusions versus fallback, first emitted mismatch including token ID and position, correct prefixes at cap, and retries. Native autonomous address selection in the client is the reference. A vacuous supplied-control win or a printed token string alone cannot certify learned source selection. Gate failure ends this collection at source ranking.
