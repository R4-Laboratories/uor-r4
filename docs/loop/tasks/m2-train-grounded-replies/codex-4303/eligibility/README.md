# Native signed word admission

The existing reader permits a signed governor when its native word point is closer in L1 distance to its own lexical bank than to the opposing bank. Equality abstains. The learned state has 32 existing lexical slots per sign and the protected starting state uses four per sign. Every slot holds the original 96 signed integer coordinates.

The TRAIN-only fit gathers the word points at positive original “retain” addresses, one per labeled turn. A GPU kernel computes the lower coordinate median. A second GPU kernel appends a center to the existing bank at one of four fractional distances from its nearest original own center to that median, with signed integer truncation toward zero. The wrong-sign arm appends the full median to the opposing bank. The ordinary reader receives only the serialized state and original-address text. The tools' `cross` operation rejects overlapping factor fields, and `probe` records both nearest lexical costs and their native slots on each original word.

The finite fixture makes a +32/+32 distance tie on the intended affirmative word, changes its affirmative cost to 24, 16, 8 and 0, then puts the full prototype on the opposite sign for a 32/0 control. The full positive restores the inherited physical source replay bit for bit. The probe and model read the same `textlinks::closest` implementation.
