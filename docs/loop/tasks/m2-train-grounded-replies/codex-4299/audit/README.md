# Independent median and source readback

The independent Wick auditor starts from the original signed governor and noun labels and the canonical typed UORTXT01 and UORSTT01 parsers. It uses a signed integer sort to recompute each component's lower median, constructs and checks every byte of each state mask, and verifies fixed-slot L1 residuals on all 512 assignments. The archived scalar joint reader replays the original-address tuple, links, ties and state on every candidate. TRAIN election checks exact protected membership and the full far pair IDs before applying the registered tie order. The auditor checks the operator's tag and its lossless native payload.

When no state qualifies, the election records the arm's starting measurement and the selected bundle carries the original protected state with the endpoint operator. The full diagnostic keeps the arm's geometry. A finite audit test checks this fallback and rejects a wrong unpacked operator or payload. Held replay verifies the captured unpacked state and operator before choosing the corresponding tape on both panels.

The held audit replays the physical lanes with both artifacts and their geometry tapes. Independent joins verify both original address coordinate systems. The comparison counts opposite-role pairs only when both original prompt identities pass. It reports the first incorrect near and far reads, ordered gains/losses by exact pair ID, and whether each matched first/later comparison followed the requested occurrence and completed both overall reads. The gate reuses the preceding independently implemented predicates, verifies all gate clauses against the physical replay, and checks the writer input enrollment against the actual joined source decisions.

The Wick calibration uses the finite device capture, which tests equal nearest-centre cost, even lower medians, zero medians, inactive sentinels and unsupported active slots. The panel audit compares fresh prompt digests with the preceding workloads and verifies the original addresses, tuple lists, lexical geometry, unchanged short-gap features and matched same-position source intervention. The [preflight receipt](PREFLIGHT.md) records the separate scalar TRAIN preparation and the [FIT addendum](FIT-v2.md) binds the physical experiment. The [grounded-reply roadmap item](../../../../../roadmap/items/m2-train-grounded-replies.md) defines the wider M2 bar.

On Wick, reuse the sealed captures and create new receipt versions for replays.

```bash
s=/mnt/plexpool/uor-r4-corpus/runs/20261126-codex-fixed-assignment-median
panel="$s/panel/panel-v1"
audit="$s/audit"
method="$audit/source-v7/run-wick.sh"
bash "$method" train v4 v6 "$panel" "$s/train-v1"
bash "$method" held v4 v6 "$panel" "$s/train-v1" "$s/held-v1" "$s/grade-v1"
```

A cold restore can run the auditor directly after verifying the private packet and historical prerequisites. Its TRAIN subcommand expects the pooled bank, protected state, panel root, historical measurement directory with `premise.json` and `selection.json`, physical TRAIN directory and a new output file. Its held subcommand expects the pooled bank, protected state, far-only state, panel root, physical TRAIN directory, TRAIN readback, physical held directory with `unpacked/`, grade directory and a new output file.
