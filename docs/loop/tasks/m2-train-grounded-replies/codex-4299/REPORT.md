## Plain summary

Fitting centers to the new coordinates fixed every previously lost protected TRAIN case. On unseen wording it changed which wrong words were read and, for endpoint, recovered parts of more long instructions. A full long instruction still never selected all its sources correctly. This locates the unresolved failure before the first output token, at the choice among competing locations in the user's text.
