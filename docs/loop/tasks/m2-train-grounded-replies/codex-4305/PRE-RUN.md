# Read a protected source with supplied governor and argument alternatives

Lab codex. The source selector must eventually identify an original address from text for the M2 writer. [Previous fresh evidence](../codex-4303/REPORT.md) identified separate failures in the signed decision word and in the argument noun even with that word pinned. All parameter words in slot 3 are frozen. This is a factorial intervention on the candidate list during readout. It supplies original-address annotations as diagnostic inputs. It learns no parameters and admits no model-selection step from held outcomes. [Order](ORDER.md)

**Independent variable.** Factor G replaces the contested role’s native word search with the supplied signed original word. It bypasses the strict own-versus-opposing sign gate only for that link, retaining the actual own-bank lexical cost and each original word-to-site transport cost. Factor N permits all author-identified action or report argument sites in the contested role. The list includes the two original same-spelling candidates, any independently offered object, and other valid action/report arguments at their original addresses. It cannot encode whether the first or later occurrence is requested. The opposite signed link and heading always use their native candidate sets. Main states are B, G, N, GN. A wrong G supplies the physically different opposite clause’s word under the contested sign. A wrong N supplies an equally large disjoint set. Cross each wrong input with the other correct input, and run a double-wrong arm. Additional supplied-link controls supply the fully correct links and exchange only the requested noun for its same-spelling rival.

**Decision rule.** Enroll 128 first/later pairs across four new wording families, eight new fact sets, contested signs and governor orders. Freeze the complete text, original byte and absolute BPE labels, argument lists, displaced controls and pair IDs before any model read of them. Compare the newly annotated argument alternatives with original text and legal tuple enumeration. A protected arm must retain the exact four archived signed switch identities and all 24 archived near full-tuple identities, each on both prompts. Run the same restrictions on the actual guard texts. A guard loss closes that configuration for promotion. Record its fresh performance as a diagnostic. No runtime fallback to baseline on known guard IDs and no choosing a mask after a held read.

A signed row wins when the device has exactly one winning complete tuple and its contested link recovers the exact original word and noun addresses. A full row must also recover the opposite link, both governors and the heading. A pair needs both variants independently. Report four crossed cells, individual guard IDs lost or recovered, first-only, later-only, both and neither, both-direction changes in paired wins, strongest ordinary wrong reads and original-address witnesses. Different governor addresses are structurally guaranteed by ordinary strict sign membership but an external signed override can admit a word that remains eligible on the opposite link. Preserve native tuple legality and report repeats of the selected governor across the two roles, plus signed wins requiring distinct selected governors. Ties and absent tuples are separate outcomes. Addresses observed in a tied first tuple do not earn wins.

**Controls and registration.** Check the unchanged state and exact D11/tokenizer/bank, native baseline across both historical device paths, all four and 24 original named guards, correct and swapped source controls, mask and first/later correspondence, and a solvable finite GPU fixture with independent G and N effects and wrong-address failures. A non-author verifies the input contracts, checksums, positive and negative control readouts and the conditional outcome criteria before qualification. Bind the exact ordinary and instrumented operator sources, AOT device build and GPU binary hashes. After the physical run independently replay original integer comparisons and native fields, recover the portable evidence on Wick, and verify an immutable private result-store download. Classify instrument failures separately and keep original attempts.

**Resources.** One rented Vast RTX 4090, approximately 30 minutes including build and transfer at the live rate subject to the shared fleet caps, with an actively monitored lease. Wick handles panel preparation and deterministic reduction with bounded worker counts. Budget 3 GiB temporary ZFS and at least 128 MiB disk headroom. Laptop work is limited to code, orchestration and checks. The historical Mac model-time ledger is absent at its documented location. Record actual storage, device time and provider uptime. A gain only under supply identifies a native relation for learning. Losses with both correct inputs distinguish failure to choose the requested occurrence from failure to complete the opposite link or heading. First wrong emitted token and EOS are outside this source-only experiment.
