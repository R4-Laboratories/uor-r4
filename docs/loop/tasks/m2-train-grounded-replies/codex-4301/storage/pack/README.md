# Portable measurement capture

The Wick packer prepares the independently sealed TRAIN material and source with
`bash wick.sh stage v1`. The `seal` phase adds returned fresh scores, ordered
artifact readbacks, supplied controls, independent evidence and physical device
records. It creates a member manifest, zstd archive and archive identity receipt.
Run `bash wick.sh cold v1` to extract into a new Wick directory and rerun the
election, each fresh grade and the supplied controls from the extracted members.

The cold check also runs the archived independent Rust verifier on each fresh
arm and both physical controls with the signed tokenizer. It compares each
complete semantic result with the corresponding original independent receipt.
All cold comparisons consume the extracted paths. The replay recalculates
scores and grades from captured physical outputs and native state, with no
new training or rental required.

The primary candidate directory retains every exported state and its originally
captured native and conditioned traces. The archived original bank and both
starting states are available under `models`. Raw source packets and original
byte and BPE addresses travel under `panel`. Prepared guard recovery remains
under `supplemental`; the measured recovery branch is present only when it
was part of the elected comparison.
