# Fitted original-address words recover TRAIN answers and lose unseen questions

## What did not work

[codex] Both fitted readers scored 0/23 fresh supported replies through natural EOS and 0/10 strict matched source pairs. Geometry selected and copied one correct interval, count selected zero. Geometry committed an original source on six of seven unsupported prompts, count on five. Neither reader found any of the ten human answer spans. All 23 supported originals were present in the candidate lists. [Device and cold readback](fit/DEVICE-REPLAY.json)

[codex] The balanced ordinary writer on those same prompts made no complete source copy and no exact reply. Its first wrong token was at offset zero for 21 supported replies and offset one for two. ## What changed

[codex] The ordinary integer client can now select an original interval from its current user turn or explicitly suppress occurrence copying. Only an artifact with the interval envelope activates the learned path. Each checkpoint wraps the same balanced writer with 4,096 signed words. The token and geometric variants share the candidate spans, the first eight structural and lexical feature banks, the update rule and tie policy. Eight other banks index ordered token context or D11 Clifford transports. A selected interval hands its original endpoints to the exact cursor. When the source ID requires a standalone leading space, the client proceeds only if the frozen writer actually emits ID 223. The current implementation supports single-user extractive inputs and spans up to eight IDs. [Product operator](../../../../../crates/uor-r4-integer/src/discrete_d11/native_interval.rs) · [Fit registration](SHEET.md)

## Measurements

[codex] The reduced finite gate found a shared integer witness for all 2,173 target-versus-rival comparisons per arm. The larger fit used 345 of 346 TRAIN rows. One target contains an internal period at an address the frozen cursor cannot traverse. The CUDA fit gave both arms 32 passes and 11,040 update opportunities. Each fit selected all 345 eligible targets, all 124 TRAIN pairs and all four protected addresses. Permuting the labels recovered zero protected addresses. The actual geometric and count fits made 771 and 700 margin updates. The cold verifier matched 203,802 scores and 2,280 selections across six complete artifacts of 1,202,185,782 bytes each. The GPU scored native keys extracted in Rust. The client replayed the same original sites, keys and signed scores from each reloaded artifact. This experiment did not measure GPU prefix extraction or GPU autoregressive decoding. [Finite gate](fit/FINITE-GATE.json) · [CUDA and cold measurements](fit/DEVICE-REPLAY.json)

## Checks run at the head

[codex] On the same fresh text, supplying the true original interval yielded 21/23 complete source copies. Native release completed 0/23 replies. Adding the independent stop at a verified end yielded 21/23 exact replies, including 8/10 human and 13/13 authored positives. Two human openings required standalone space ID 223 but the frozen writer emitted 30 or 4. Both abandoned the supplied cursor at offset zero. Supplying only stop to the learned geometry and count readers yielded 1/23 and 0/23, respectively. On the matched authored pairs, giving each original prompt its partner's learned source decision yielded 0/10 paired wins and 0/13 supported exact native replies with either reader. The geometric partner reads copied on five of seven unsupported prompts, the count partner reads on all seven. [Same-prompt causal controls](evidence/ordinary.json)

[codex] The protected four preserve duplicate original source addresses. Both actual arms issued the correct full copies on 4/4 and completed 0/4 native replies. Each reference also required a period after the value. Supplying EOS immediately after that value failed 4/4 at the required period. A correct protected address is an address regression check only. [Protected comparisons](evidence/ordinary.json)

## Plain summary

[codex] The same native weights that fit virtually the entire TRAIN panel also passed cold client score replay. Changing the question often changed the selected interval, yet both sides of an unseen pair were never correct together. The next study has 638 mechanically verified pairs of real questions that ask for different facts in the same passage. It can test whether learning from those reciprocal questions improves transfer before increasing model size or GPU time. [Prospective supply census](evidence/next-supply.json)
