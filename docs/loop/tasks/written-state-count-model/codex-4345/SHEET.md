# One optional learned EOS promotion on the frozen ordinary writer

[codex] This is an M2 development experiment within #4063. #4319, #4322 and #4341 isolated failures after correct copying, and #4344 found no matched natural grounded release actions. This trial asks a different, directly supervised question: can the existing ordinary writer's geometric state predict observed reply completion beyond position and punctuation? The supervised target is precisely the action in SUPPLY.md. A source address and an unsupported natural reply are separate outcomes.

**Frozen base and output.** Balanced D11 SHA-256 5c98e60db9011890d3dbce42f197c8703cfb75865e85ee61db2c364a8624c2aa, tokenizer a9fb13f70c69ffe5afed40c8251a8e702adf0b00732d35ccff9457a3309ee377, observed original protocol-2 BOS through the causal prefix (up to 191 before its next target). Every 16-bank × 256-key table contains exactly 4,096 LE i16 words. Sum one value in each bank in i32. Score > 0 promotes bound EOS; zero or negative commits the previous writer's choice, including any EOS already proposed. The intervention cannot repair a premature native EOS. Authentic copies or supplied stop commitments take precedence. Fixed checks include the raw base, identical artifact with bank off, fixed stop after .!? in the previous visible answer, and a same-size ordered-prefix bank. Compare both complete deployable artifact sizes including header and shared tokenizer. This is a termination comparison only. A zero-state packaged table also needs to preserve the base's output at the tested transitions.

**Features.** Compute geometric addresses from the causal writer's read code/vector, recurrence code and relative native geometric transforms across four blocks. The ordered control uses the same number of signed entries, summands and training operations and hashes ordered pairs of original causal IDs to each bank. No answer length, remainder, target, speaker stop labels, corpus ordinal or true action enters the scorer. A feature carrier is acceptable only if its integer score agrees with cold-loaded serving on each replayed event for both arms. Record the exact Rust and AOT source pins and feature definition before run. The CPU extracts the same typed keys used by serving; CUDA owns all real weight updates and qualifying bank scores. This scope does not measure full GPU writer execution.

**Schedule and blinding.** Use every registered strict TRAIN pair, 32 epochs, fixed seeds 1 and 2 from all-zero tables. Deterministically shuffle TRAIN pairs per epoch with SplitMix64 Fisher–Yates. For a pair update from both pre-update scores. For STOP score < 1 add 1 on its keys; for CONTINUE score > -1 subtract 1 on its keys. Combine simultaneous same-address deltas before saturating i16. Score all held events label-blind for all four fits. No thresholds, seed or epoch chosen with dev or held scores. Include each earlier stage denominator in SUPPLY.md. Report pair wins (both final committed actions correct, and both learned sign decisions separately), missed final EOS, premature EOS, agreement with disabled and exact STOP and KEEP counts, including ties. A fixed punctuation baseline has the same disabled writer fallback. Permuting both labels on the same matched pair must reverse correctness. Zero must preserve the ordinary ID.

**Ordinary serving.** Generate from the complete protocol opening to 192 emitted IDs or actual EOS for each distinct held turn under base, fitted geometry and ordered arms, both seeds. Admission of these turns is selected on teacher-forced events. Self-feed every predicted ID. Keep prior genuine history, with EOS, from the donor; the current answer is unseen to the generating process. Compare emitted IDs to the original full visible answer and natural EOS separately from the one-step teacher-forced action; count first differing one-based position and expected/emitted ID, premature and late EOS, cap, exact-through-EOS and answers over budget. Fixed punctuation can be exactly reconstructed from the baseline's self-fed path up to its first triggered commit; label this reconstruction. One-step boundary wins cannot establish chat usefulness. Any causal mask-0 earlier reply may be compared to its observed protocol EOS but is a separate stratum. Keep synthetic/wrong controls separate.

**Decision.** Supply gate in SUPPLY.md and nonauthor FIT before real device work. For either seed a regression against the base in complete replies or premature EOS blocks promotion. Require both geometric seeds to beat disabled, punctuation and ordered in two-sided held pair wins and to improve complete ordinary replies through EOS for further transfer evaluation. A high teacher-forced score without self-fed improvement routes back to earlier generation errors. A loss to ordered calls for a different representation or fit before increasing compute. No model-default change at this stage. Natural fit on previously exposed donor cannot qualify external transfer.
