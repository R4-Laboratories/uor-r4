The cancel probe recovered the #4320 negative and its #4319 packed artifact on Wick. Freeze the existing writer, authenticated copy and model parameters. Supply the opening word, its original position and the first period. Train the weights that choose between EOS and the next verified original source address, once after the period and again after every copied follow-up. The model receives the same ordered factual address inventory on both sides. Count source selection as supplied and action choice as learned.

Use two independently reported paired contrasts over sequences A., A. B and A. B C. In the primary contrast the same factual B is final on one wording and followed by C on the other. Also test stop at the first period versus following it with B. Use matched factual words, frozen source positions and opposite directives. Each row provides a further eligible address D so exhaustion cannot reveal the last requested action. A point of failure is the first wrong committed token on the self-fed trajectory. Independently score the matched decisions at the common prefix and full exact pairs through emitted EOS.

Native state comprises frozen D11 root coordinates and all existing writer/copy state, three signed i16 sparse geometric address tables and signed biases for the three release positions, plus the action stage, source positions and original IDs. Score a distinct set of root unigram/ordered-adjacent-pair buckets in the current directive and the stage bias with integer arithmetic. A signed TRAIN margin update writes the same native words cold serving reads. The learned action emits EOS on a negative score, reads the verified original token on a positive score and uses the native proposal on zero. A verified copy advances the release stage. Each release also has a fresh unchanged native proposal. Keep full native, own learned, actual paired opposite learned, correct action and opposite action controls. Bind the learned state in a lossless D11 envelope around the unchanged #4319 D11. Test deployed Rust versus GPU events at zero tolerance, including real committed tokens, sources and stage. Preserve native EOS and distinguish it from explicitly selected EOS. Scope is bounded to the native head, paired panel, product opt-in and this experiment; an instrument mismatch invalidates scoring.
