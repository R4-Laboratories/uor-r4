# Pre-registration for learning the release action

**Question.** When all eligible factual addresses are available and fixed, can signed weights trained on wording select EOS or the next authenticated address at the appropriate release? Use the frozen #4319 D11 (`93147372d495b36fda03fa0115a983e75bf1fd1b132d826212b4e1e0e6a1e89a`) with #4318 copy and the native writer. #4320 found that an unchanged writer proposed 73 after 400 correct periods and was never exact. The new panel, including its native arm, supplies its own comparison. Freeze the actual TRAIN/finite/held tapes and tool revisions before fitting.

**Panels.** Register 200 independent fresh pairs where the same B is final or followed by C (A. B / A. B C), plus 200 other pairs testing release at the first period (A. / A. B). Within each pair the facts, person, roles, original word addresses A–D, their IDs, question and assistant marker are identical. D is always eligible. Counterbalance facts, wording variants and punctuation as documented by the concrete panel. Use whole wording families withheld from TRAIN and an independent instrument panel. Record repetitions of wording, literal source identity, family and spot-checked decoded references. EOS is ID 1, period 16. Require at most five commits through EOS, with all available candidates supplied independently of expected length.

**Fit and comparisons.** Learn only three sets of 4,096 signed i16 weights plus one bias per release (24,582 bytes). The signed i32 sum on the distinct #4319 directive root and ordered adjacent-root addresses and stage bias selects copy for positive, EOS for negative and the ordinary writer on a tie. Fit on TRAIN for eight fixed ordered epochs. Apply unit signed margin updates to reachable gold prefixes with target margin 8. Also update the feature difference at the shared opposing stage for an insufficient pair separation of 16. Preserve equality/refusal behavior exactly between device and client. Register the deterministic schedule and seed in the source and tape receipts. The learned arm gets the prompt, stage and common verified source inventory. Correct/opposite action labels, paired prompt, shared-stage contrast and reference are available only to their explicit controls or scorer. Zero-state calibration demonstrates the ordinary proposal can win. Device fits native words; a D11 envelope stores exactly those bytes with the original model.

**Endpoints.** Count shared-prefix decisions where both wordings select the right action, inverted pairs, equal actions and abstentions; also count pairs that actually reach that prefix on their own rollout. Independently report exact STOP-side, CONTINUE-side and paired replies through EOS, first wrong emission by position and actual ID, natural versus selected EOS, authenticated address identity, and paired gains/losses vs native and swapped. Show the result for each contrast and family, with both oracle controls. A sign flip in isolation is ambiguous: positive transfer requires more fully correct pairs than native and swapped, and positive correctly oriented common-action pairs on unseen wording; report its extent across families. A constant action at the common stage can win zero complete opposite-action pairs. Interpret family consistency separately from fact counts. There is no scaling or milestone threshold in this diagnostic. Oracle failure, source contamination, broken controls, duplicate training/held prompts, or byte/transition parity disagreement invalidate affected measurements.

**Run and decision.** The leased SM89 RTX 4090 runs the AOT integer operator, guarded by a source/input/image-bound GO after independent FIT and finite checks. Fit once, freeze the resulting state digest before held scoring, reverse-reload GPU and compare with cold D11 output on Wick. Estimate minutes of qualification on a single rented 4090; release as soon as raw evidence returns verified. If transfer is strong at one release only, target the other under the same controls. If TRAIN succeeds and held fails, use paired TRAIN diagnostics to address wording generalization before more capacity. If learned and oracle both fail, repair the instrument. This experiment leaves independent address discovery and free conversation open.
