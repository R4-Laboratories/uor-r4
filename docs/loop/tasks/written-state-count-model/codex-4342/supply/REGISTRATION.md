## Source review and stop

Each reviewer checks every annotation for a sufficient, unambiguous answer and flags competing or underspecified answers. The reviewer checks same-target questions for equivalent requested facts, scope and roles. Across targets the reviewer distinguishes a switch between different facts from a strict reversal of the same expressed relation and argument roles. Support for an endpoint alone proves neither equivalence nor reversal. Require both reviewers to agree on the group contrast and support all rows before any group enters the label-blind structural input. Preserve individual reasons, unresolved groups and disagreements.
