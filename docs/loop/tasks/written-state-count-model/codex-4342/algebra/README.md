# Finite orientation check

The driver reads the four literal tables used by the production runtime and compiles an independent Rust oracle. It checks composition as actual signed-axis action on a vector whose components distinguish all axis permutations and signs. It checks every canonical path against its original root endpoints and every group inverse in both orders. It then enumerates all four-root inputs to verify the proposed key and the source-order intervention. This test measures representational support. The relative frequencies under uniform roots do not estimate the frequencies in language.

Run `bash check.sh path/to/discrete_d11.rs /fresh/scratch/directory`. Slot zero is reserved for a missing endpoint and is outside the enumeration. The 64 populated slots can all be reached. Observed controls and order-sensitive counts are in [the finite receipt](../evidence/finite.json).
