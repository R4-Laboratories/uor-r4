# Changing the recurrent source removes old collisions but introduces different ones

## What did not work, first

[codex] None of the four fixed address maps supports the registered 3,109 simultaneous strict wins on the 3,886 authentic TRAIN openings with frozen P4 priors and four additive lexical words. On the original pairs the transported D11 midpoint erased 1,219 of 1,334 contradictions. Comparing every candidate token found 1,357 disjoint contradictions under that same operator, limiting simultaneous wins to 2,529. In the selected matching, 1,342 of those 1,357 row pairs differed from every pair in the old matching. The changed read left the first content token wrong on the ordinary-client sentinel. The full-census bar closed each configuration before fitting. This experiment has no new held reply or EOS count. ## What changed

[codex] The existing D11 recurrence computes a midpoint root transported by the suffix’s group action. We exposed its normalized four roots as an optional lexical address operand in native Rust and CUDA. A second operand uses the same midpoint and normalizing frame with identity transport. The existing snapped operator remains the default. The ordinary client loads the selected tagged operator and exposes its name and carry. Each tagged attachment contains the same four banks of signed words and occupies 584 bytes. The count model, copy path, prior, candidate IDs, tie convention and writer are shared. A fourth research control borrows the carry from a different real conversation while keeping the recipient’s own frozen prior and token candidates. ## Still open

[codex] The experiment closes these four additive address maps on this measured population. A next candidate is one learned score indexed by the native ordered Cl(0,6) product of two bank transforms. In some pairs the other bank’s transform changes the context of an otherwise opposing constraint; one joint lookup can distinguish those cases. Seal one choice of bank pair before measuring it. At most 64 i16 slots are needed; the current layout contains 152 unreachable words across its four banks. Using some of them preserves the head’s stored bytes while increasing the number of usable coefficients. Include a control with equal active words as well as equal deployed bytes. Rerun the complete rival test before fitting. A ceiling above the bar only permits the next experiment. Require an actual trained shared assignment, transfer to disjoint conversation groups, and self-fed ordinary chat through natural EOS to establish language progress. ## Plain summary

[codex] Changing which part of a conversation the four scoring banks read changed the tokens they chose. Most old conflicts disappeared, including with the wrong conversation’s address. Other real conversations then required mutually incompatible settings of the same weights. Future training needs a way for one learned contribution to depend jointly on more of the current context.
