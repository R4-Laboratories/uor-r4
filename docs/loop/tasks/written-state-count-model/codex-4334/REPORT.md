# Moving the request boundary preserves the shared source-ranking conflict

## What did not work

[codex] Retain the balanced checkpoint. Measuring the request relative to the supplied passage separator or the ordinary client's trailing-32-token boundary changed every tested source representation. Neither frame admits one 64-byte table that ranks the 13 supported answers above the other original token addresses. This holds at margins 1 and 8 with frozen scores and with both offsets zero. At zero offsets, each new proof cancels every coefficient. More training or a wider word bound on this additive score cannot produce the missing rankings. GPU rental cost was $0. ## What changed

For each candidate, the probe expresses its four native roots in a frame selected by the request-end state and the state just before the cut. Both have the same 32 bounded i16 words, eight signed contributions per site, original candidate addresses, 513 inherited weights and fixed writer. The previous zero anchor is the reconstruction control. Product and independent recurrence agreed on 2,768 raw words across 36 prompts and 2,624 sites. Within a prompt, the two cut offsets and the two cut states differed in all 36 cases. The panels were already exposed in #4333, including its institution-address caveat. ## Measurements

The primary comparison uses 13 supported questions and 1,056 gold-against-rival source comparisons. Each question can beat its rivals with its own table, 13/13. A shared table can also put the correct source above NoRead on all 13. Requiring one shared table to beat the competing original addresses fails. The following are exact contradictions at margin 1, native query and zero offsets.

| Frame | Conflicting comparisons | Required weighted sum | Maximum possible sum |
|---|---:|---:|---:|
| Previous zero anchor | 33 | 150,844 | 0 |

| Ordinary trailing 32 | 33 | 8,365,541 | 0 |

The old proof broke in both relative frames. Every one of its 33 coefficient vectors changed. Solving the complete set generated new proofs. The separator proof involves 25 passage rivals and seven question rivals. The trailing-window proof involves 31 and two. All four geometry arms separately admit a pooled positive source-over-NoRead solution in both offset and margin settings. All fail pooled source ranking. [Certificates and controls](gate/README.md)

With all sites and the five unsupported questions present, all three frames admit 8/9 actual-query fresh pairs with inherited scores when each pair chooses its own table. The same unsupported question about the father's teaching institution remains individually infeasible. The swapped-query arm separately admits 8/9. Swapping the query while holding each of the eight actual-query witnesses fixed preserves 0/8. The fixed-query arm admits 3/9 with the separator and 6/9 with the trailing window. In all three additional fixed-query pairs the two wordings give different trailing cut indices and the same separator. Wording length can change this control's anchor. On the earlier nine, all frames admit 8/9 actual-query pairs. None admits a single all-rival table across the combined panel. [Counts and proof replay](evidence/gate.json)

The full coordinates retain distinctions that their tested additive score cannot use. Learning what those distinctions mean on unseen questions remains open. ## Plain summary

Both boundaries change the information presented to the score. Neither lets one set of additive weights distinguish the right words from other word starts across requests. The complete geometric state still distinguishes the occurrences. The next experiment can test how the roots interact at the same storage budget.
