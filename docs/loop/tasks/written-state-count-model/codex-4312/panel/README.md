# Held-out prompts and blind grading

The panel uses the same 4,096 original token IDs and literal-role v2 protocol as the candidate native checkpoints. The longest opening is 192 tokens. A prompt includes its closed earlier assistant EOS tokens and ends with an open assistant marker. The ordinary client can slide its context during emission after the initial opening. The panel is frozen before training and evaluating either candidate.

| Cohort | Independent units | Output cap | Observation |
|---|---:|---:|---|
| Passage-grounded human dialogue | 200 conversations | 32 tokens | Completion of an objectively checkable conversational request and first emitted EOS |
| Contextual code recall | 32 independent pairs, 64 openings | 32 tokens | Correct code and EOS for both assignments in a counterfactual pair |
| Wikipedia prose | 128 articles | 64 tokens | Teacher-forced scores on original prose, generated token novelty and repetition, and agreement with one observed continuation |
| Open human dialogue | 32 conversation trees | 128 tokens | Blinded human review of the emitted reply and actual terminal status |

## Passage-grounded conversations

CoQA development release v1.0 provides the original paired human questions and answers and three independent annotations for the selected target. The panel takes at most one target from each conversation and normalized passage. Each selected target follows one to four unchanged user and assistant exchanges. The original final question is included, and the target answer is withheld. The final cohort has 152 factual slots, 24 yes answers and 24 no answers. All questions were checked against the exact normalized D87 prompt bank and its 40 follow-up templates. The sum of 200 selected rows comes from 72 Gutenberg, 65 CNN and 63 Wikipedia conversations. [CoQA dataset and licenses](https://stanfordnlp.github.io/coqa/) · [Reddy, Chen and Manning (2019)](https://aclanthology.org/Q19-1016/)

The initial carrier cap cannot fit the complete passages. Passage windows use the maximal contiguous sequence of original sentences under the fixed 117-token construction budget, independently for every source sentence start. A window is eligible if it contains the full normalized human-marked evidence for the final answer and fits with the complete prior dialogue. The selected window is ranked by a fixed hash. The model receives the resulting original excerpt without the annotation, highlight, answer alias or source row identifier. Evidence-conditioned window admission makes this an assisted passage-reading question, and limits inference to that setting. The evidence for a previous answer may lie outside the excerpt because the unchanged previous answer is already given in the history. Exactly 209 distinct source conversations had an eligible target and 200 furnished the fixed draw. An earlier attempt that also required in-window evidence for the prior recorded answers yielded only 83 eligible conversations.

Factual rows require agreement from the original answer and at least two of three additional human annotations on a normalized short slot, and independent evidence for it. The slot must be absent from earlier assistant answers and the question. A yes or no row requires unanimity on polarity. Whole-answer parsing admits short direct replies, constrained grammatical paraphrases, and small number equivalences. A correct value buried in unsolicited prose, a contradictory or alternative value, a question echo, and an empty reply fail. EOS is required for the primary useful-completion outcome. The grader also reports whether the response content resolves the slot independently of EOS. An emitted BOS or UNK is retained in the observed tokens and produces a malformed reply, even when EOS follows. A transport stream ending without EOS or its specified cap is incomplete.

The retained human reference passes the frozen scope on 200/200 records. The other independently annotated references pass on 545/600. Coverage depends on a short, conservative answer grammar and misses some valid expressive paraphrases. The human-reviewed subset is where open-ended response suitability is assessed.

## Independent controls

The recall set uses the same context/distractor/recall structure as the existing entity-recall fixtures. For a fixed question and ordering of named entries, each counterfactual preserves all text except for an exchange of two newly generated five-digit values. The queried north or south slot is balanced across pairs. Each competing value is present in the prefix. Both assignment variants must resolve correctly through EOS for pair success. [Entity-recall fixtures](../../../../../../tests/e2e/fixtures/entity_recall_dialogue.json)

The prose set uses English Wikipedia snapshot 20231101, shard 00021, with one opening per article and no overlap with prior panel article IDs or the CoQA Wikipedia title inventory under exact normalization. Each opening is BOS plus 127 original token IDs. The next 64 contiguous original token IDs form reference positions, including at least eight emissions whose IDs are absent from the starting prefix. The teacher mask also identifies novelty relative to the growing reference history. Exact continuation agreement earns no claim about fluency or all possible valid continuations. The data receipt retains title, URL, source row and snapshot attribution for each excerpt. [Wikimedia dataset](https://huggingface.co/datasets/wikimedia/wikipedia) · [Wikimedia content reuse](https://www.mediawiki.org/wiki/Wikimedia_APIs/Content_reuse)

The 32 open prompts come from distinct OASST2 ready, reviewed, non-synthetic English trees. Every chosen prefix preserves the originally recorded earlier assistant turn. The walk excludes previous panel tree IDs and the historical holdout bucket, exact D87 prompt-bank hits and exact D87 follow-up template hits. A deterministic request-phrase screen admits follow-up requests, explanations, writing tasks, and open question forms. Some wh-questions still have a short factual answer. The custodial transcript is supplied to human judges, with no gold reply and no treatment identity. The exact D87 and panel checks establish freshness against those inspected sources. They leave approximate matches and other historical exposure unmeasured. [OASST2 dataset and license](https://huggingface.co/datasets/OpenAssistant/oasst2)

## Custody and interfaces

Run the Rust binary with the pinned inputs and an unused output path.

```sh
visible-answer-panel build TOKENIZER COQA WIKI OASST2 D87_BANK_DIGESTS PRIOR_FIT PRIOR_HELD 192 NEW_DIR
visible-answer-panel grade TOKENIZER SEALED_PANEL BLIND_GENERATION_JSONL ARM_COUNT NEW_GRADE_DIR
visible-answer-panel stats SEALED_PANEL BLIND_GRADE_DIR ANONYMOUS_GPU_TEACHER_JSONL NEW_STATS_DIR
```

- Generation receives only `prompts.jsonl`, with fields `id`, `domain`, `prefix` and `cap`. Teacher-forced measurement reads `teacher.jsonl`, which adds reference token IDs and the per-position novelty mask and omits the open cohort.
- The blind grader receives a complete matrix of rows containing exactly `id`, `arm` and `tokens`. Each identifier is 24 lowercase hexadecimal characters. The custodian supplies the secret treatment assignment separately after grades are sealed. EOS is included when emitted. The per-arm raw reply file can therefore be checked without access to the arm key or any gold continuation at generation.
- `judgments.jsonl` serves the deterministic conversational and recall scorer. `open_sources.jsonl` contains the earlier human transcript for the human packet. `prose_sources.jsonl` contains attribution per prose row. The artifact receipt binds all file digests.
- Blinded outputs retain raw tokens, decoded text where UTF-8 is valid, EOS and cap status, content correctness, malformed-token incidence, and per-row first reference divergence where applicable. The summary reports named paired cells under opaque arms, first model-to-model divergence positions, and completed recall pairs.
- The inference command authenticates the grade receipt, both blinded matrices, reference identities, novelty masks and exact cohort counts. It writes `blind-stats.json` in opaque lexicographic arm order. Differences are right minus left. It uses 10,000 paired unit bootstrap draws at seed 4312 and an exact two-sided binomial test on the discordant conversations. With zero discordances it includes the exact one-sided 95% bound on any directional difference. It also reports upper bounds on zero arm successes. Recall uncertainty uses the 32 independent counterfactual pairs. Prose teacher forcing resamples whole articles and retains both the position totals and matched article count. Free generation includes first token divergence, reference mismatch, EOS/caps, recurring openings, lexical diversity, and contiguous copies of input token IDs.
- The restricted panel and grades carry corpus text or reversible IDs. CoQA uses the Stanford-listed CC BY-SA 4.0 Gutenberg and Wikipedia passages and CNN source marked Apache, with CoQA attribution and original source filenames. OASST2 is Apache-2.0. The Wikimedia snapshot lists CC BY-SA 3.0 and GFDL subject to the original article's terms. The prose custody retains the original attribution URLs and revision identity. The project retains the raw corpus in the run storage alongside the separately pinned paths and checksums. [Pinned Wikimedia license](https://huggingface.co/datasets/wikimedia/wikipedia/blob/b04c8d1ceb2f5cd4588862100d08de323dccfbaa/README.md)
