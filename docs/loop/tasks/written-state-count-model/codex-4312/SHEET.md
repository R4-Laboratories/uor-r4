## Held panels

The geometry objective is fitted first, followed by complete count-table fitting on that arm's learned state. This design estimates the effect of the rendering under this staged training recipe. The two fresh arms are the only arms measured on the new panel.

1. Primary. Select 200 fresh, separate human CoQA dialogues/passages, each with an actual earlier human question and answer. Use the same source excerpt, history, final user request and protocol for both models. Keep every prefix within the supported 192-token initial window. Fix the draw and report excerpt selection, actual strata, human agreement, exclusions, earlier-source checks and any residual overlap risk. The grader recognizes closed factual/polar replies with multiple human references and approved equivalences. Require termination by EOS and complete answer compliance. A cap, empty, incorrect, contradictory, irrelevant or echoed answer fails. Report content hits without EOS and clearly distinguish the operational score from broader human judgment. Ordinary greedy generation has 32 new tokens total including EOS.
2. Recall. Thirty-two counterfactual pairs (64 prompts) exchange the requested fact in genuine-looking multi-turn context using disjoint fresh values. Score the current correct fact through EOS, stale or other-fact false claims and paired switching. A paired switch requires both correct in original source order. State which histories are constructed.
3. Prose. Use 128 fresh Wikipedia articles from a different source shard; score the next-token top-1/top-8 rates overall and on reference tokens novel to their causal prefix. Aggregate by article for uncertainty. On independent free generation (64 tokens), record EOS, lengths, distinct output, repetitions, and original prefix copies. Lexical precision at a fixed reference continuation and style diagnostics do not establish human prose quality.
4. Secondary open chat. On 32 fresh English OASST2 multi-turn conversations, preserve human assistant history, use ordinary 128-token generation and prepare an offline human rating packet with balanced per-pair positions, both complete replies and their actual EOS/cap. Freeze 0/1/2 usefulness and left/right/tie/cannot-judge ratings. Raters get dialogue and replies without model name or gold. Results remain pending until people return ratings.
