# Two-factor first-period update experiment

**Decision and scope.** On fresh matched wording after an authenticated word and supplied period, does fitting both members' signed margins help the learned choice of EOS or the next verified source? Reproduce the #4321 baseline under the original 768-row TRAIN tape (384 pairs, 192 per contrast). The frozen writer, tokenizer, four supplied factual source positions, score features, sign threshold, stage transitions and cap of five commits stay identical. Keep the post-B and post-C weight rows byte-identical across every arm. Verify the baseline state SHA-256 `90f25068372afe973bd1f833a997aebe60cf843d6e5f6a71f042068005af8b6c` and reproduce the original 50/50 exact two-versus-three word-count pairs.

**Four equal-budget fits.** Train all configurations from zero on the registered original TRAIN records for eight epochs with signed margin 8. Baseline repeats the original single-example and pair-gap passes. Balanced alone alternates STOP/COPY individual updates at the first period over 768 opportunities per epoch (384 of each). Traverse the original order within each class and rotate the starting position by 384 per epoch, modulo class count. Every record is seen over the experiment. Weak alone keeps the original first pass and replaces the stage-zero difference update at each opposing pair: if the lesser of the shorter member's negative score and the longer member's positive score is below 8, update just that member by one signed unit, including bias. Break equal-magnitude ties deterministically by epoch plus opposing-pair ordinal parity. Combined applies both changes. The number of opportunities and dimensions are fixed; actual writes and per-record exposures can differ. Stage 1 and stage 2 retain their original training loops. The original inference image is used to score all four fits.

**Input and controls.** Each fresh DEV and HELD split has 200 first-period pairs and 100 post-B pairs on separate wording families, authored and sealed before fitting. Report the number of distinct directive pairs, punctuation variants and facts. Retain all 50 original passing post-B ceiling pairs separately. For each configuration and split, record ordinary native, learned own wording, actual swapped wording, correct action, and opposite action. Confirm first token/period and factual addresses match, a real EOS terminates, and a cap without EOS fails. Only signed training updates and deterministic evaluation use reference labels. The normal client receives the prompt and four factual positions. Record short/long class score distributions, both signed margins, directed paired flips, reachable decisions, exact shorter/longer replies and exact pairs through emitted EOS, first mismatch ID and position, and individual paired gains/losses.

**Two-phase protocol.** First score all four arms on full TRAIN, DEV and the original protected set. Before evaluating any fresh HELD prompt, inspect those results and require: (1) more correctly oriented first-period TRAIN pairs than the reproduced baseline; (2) more correctly oriented first-period DEV pairs **and** more fully exact first-period DEV pairs than the same baseline; (3) all 50 originally passing complete pairs retained. Require correct/oracle and opposite controls, bit-identical cold/device trajectories, stable frozen rows, and numerical finite tests. Among eligible treatments sort by DEV first-period exact pairs, then DEV first-period correct flips, then TRAIN first-period flips, then fewer interventions, then balanced, weak, combined. Publish baseline and only that finalist on independently sealed HELD requests. If none qualifies, retain HELD unopened and report which requirement stopped each. These are model-selection criteria, not a statistical claim. Base the transfer interpretation on held wording types as well as replicated factual contexts. A fresh-held gain with intact controls licenses broader grounded-language training, a TRAIN-only gain calls for inspecting wording or calibration, and protected losses call for testing a representation of when a word is still required.
