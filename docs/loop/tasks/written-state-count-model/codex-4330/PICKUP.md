# Can the learned question state change the score of a particular source?

Keep the balanced artifact as the reference. The latest four-epoch reader could not meet opposite margins on the same original source when the question changed. The clean authored control showed this on 144/144 TRAIN and DEV support flips. Spending more on the same features cannot fix that constraint. The earlier marker/state experiment already found changes to the recurrent code on 388/400 question swaps and to the read address on 376/400; its target ID was absent from the selected learned row in 748/800 assignments. A changed question state alone did not give a useful first token. [Earlier ordinary result](../codex-4314/REPORT.md) · [Current diagnosis](REPORT.md)

1. Take a new identity- and wording-disjoint panel of minimal support/NoRead and requested-source flips. Use controlled positives and independently adjudicated natural pairs. Have reviewers establish support from the whole passage on both sides, reconcile ambiguous or mislabeled annotations and seal a fresh panel before looking at scores. Keep the same-passage/identical-token controls. Keep the current used reserve as a regression panel.
2. At the true assistant boundary capture the existing native pre-marker recurrent state and each candidate's causal state at its original address. Test one shared i16 slot indexed by the four-block recurrence agreement mask at each original address, alongside the frozen 513 words. Match its budget with a control using a fixed request code. Use one small shared trainable integer table. No gold site, answer prefix or explicit question class at serving. Keep the same candidate and writer budget and require train/serve typed parity.
3. Before spending training time, run a finite two-question/two-source fixture with both assignment swaps. Require distinct feature indices at the causally correct address when support reverses and the ability to reverse the two address ranks when the requested entity reverses. Record the signed feature difference between the two candidate addresses under each question. If it is identical across a requested rank reversal, an additive readout cannot meet both inequalities. Check equal-token wrong addresses and no-question/permuted-question controls. A prompt-wide scalar cannot change relative candidate rank. Record how many real TRAIN pairs still impose incompatible inequalities before running a fit. If the proposed comparison still erases the distinction, stop there.
4. If that gate passes, train against competing original addresses and explicit NoRead with budget equal to the reference. Keep the writer and ordinary client fixed, report complete paired decisions, authenticated first emissions and self-fed replies through EOS as separate outcomes. Require transfer to fresh human wording, the protected addresses and useful open-ended conversation before promoting any checkpoint. A remaining post-space problem requires an actual space to have been generated first.

This is one bounded test of native conditioning. It neither forecasts a frontier-model completion date nor establishes that source copy alone will solve prose, reasoning or free chat.
