# Ordinary discrete dialogue probe

Seal the 16 independently constructed conversations before serving. The 22 turns comprise 10 standalone requests, six first turns with context, and six follow-ups. There is no external grader. No source positions, target reply, supplied opener, or system prompt is sent to the model. Every call uses greedy decoding with a cap of 16 emitted IDs, including any actual EOS. A fresh process opens the artifact each turn.

Use the unmodified `uor-chat --discrete --tokenizer --say` product entry for first turns. Use the same product binary with `--discrete --prompt-ids` for subsequent turns. Preserve the exact generated IDs up to and including the first natural EOS, or every ID if exhausted. Append only the prescribed protocol-2 framing and next user's message. The raw-ID mode may continue after its first EOS. Record that raw output, but stop the scored text and the history at the first EOS. Never add a synthetic EOS to an exhausted reply. Check the text entry's prompt IDs, stop and decoded text against the tokenizer and raw IDs. Attempt the grounded helper without positions and check that the stack client reports its unsupported schema on both fitted files.

A text match means the entire decoded response equals a literal accepted string after the protocol's removal of its one leading space. Report exact text and observed EOS separately. Exact through EOS requires both on the same turn. An exact conversation requires every turn to be exact through EOS. Score first and follow-up turns independently so an earlier miss does not hide later recall. For a qualitative usefulness count, credit a turn when the reply clearly answers the question, follows the requested format except for harmless surrounding punctuation or case, and avoids contradictions, unrelated text or looping. Record a plausible but incomplete answer separately if it addresses the request without supplying the full answer. Count EOS according to its emitted token even on wrong or empty replies. Preserve all text so the qualitative judgments can be audited.

Use both packed fits and the frozen #4319 base. Compare full prompt and generated IDs, text, termination and exactness record by record, excluding only artifact identity and model schema. This probe observes product behavior on a small convenience set.
