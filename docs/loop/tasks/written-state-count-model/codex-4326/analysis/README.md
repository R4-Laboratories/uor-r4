# Grade the frozen release components

Run `bash grade.sh RUN_ROOT NEW_GRADE_DIRECTORY` on Wick after the returned GPU outputs have been sealed in `RUN_ROOT/measured-v1/OUTPUTS.sha256`. The grader verifies that the full GPU observations match the original joint checkpoint and that the zero-residual observations match the archived linked control. It joins each panel and each scorer output on `(pair_id, side)` and checks the expected IDs, full prefix IDs, source IDs and positions, family and contrast. It uses the original TRAIN, HELD and historical keys checked against their manifests. It reads GPU observations and executes no model.

For a restored packet pass its archived input directory as the third argument. The archive manifest binds the flat `panels/SPLIT.jsonl` and `panels/SPLIT.keys.jsonl` files, the `historical/SPLIT/{zero,full}.jsonl` comparisons and `previous-grade/SPLIT/{balanced,linked}.rows.jsonl`. The per-panel `INPUTS.sha256` records invocation paths. The row, pair and summary outputs have path-independent contents.

The four checkpoint labels are `zero`, `period_only`, `post_b_only` and `full`. The signed stages come from the same realized joint fit. At the period the grader uses the ordinary learned trajectory. After B it supplies the first action, then requires the correct opening, a physical copy at the original B position with the original token ID, and an unforced post-B decision. The post-B comparison is eligible when both sides require B, including the two-versus-three direct pairs. End-to-end replies use the ordinary learned trajectory through EOS. The JSONL records include the first mismatching token position, expected ID and observed ID for each arm.

`strict_directed` requires a negative score on STOP and a positive score on COPY. At zero the scorer follows the native continuation. `actual_matches` counts the emitted target IDs, while `actual_authenticated` also requires the expected tagged physical copy. `actual_with_native_zero` identifies successful actual decisions where a member used zero-score fallback. A positive pair gap is the COPY margin minus the STOP margin. A strict flip by the same integer score shift on both sides requires a gap of at least two, so the summary distinguishes wrong or equal order, a gap of one, and sufficient separation with a missed threshold.

The pair ledger counts original clause-order and direct pairs using their original IDs. It reconstructs selector-only views from the sealed selector IDs when present. Earlier scope panels already carry both axes as distinct pairs. The paired transitions from each component to full distinguish preserved, erased, gained and never-correct pairs by stable ID. Each panel also reports which previously exact balanced or linked pairs remain exact.

Score additivity is tested on every row at the period and on every row with an authenticated B in all four scorers. The causal read signatures and original addresses must agree before checking `full = period_only + post_b_only - zero`. The raw score is a signed i32 sum with no runtime clipping. The grade ledger retains any residual mismatch and the observed extrema, so a score-integrity discrepancy is visible before interpreting action changes.

The top-level `summary.json` contains panel counts and the `SHA256SUMS` ladder. Each panel's `rows.jsonl` keeps the authenticated decision traces, `pairs.jsonl` keeps both members and their same-ID transitions, and `summary.json` keeps family views, representative examples and full historical identity lists.
