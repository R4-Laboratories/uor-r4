## Representation and dose

This is an explicit template-bound instruction locator shared by all model arms. It does not look up ending words or family tags. Pack each native token’s four D11 root coordinates as four low nibbles in coordinate order. For packed code c, its unigram address is `(c ^ (c >> 7)) & 2047`. For an adjacent ordered pair let v be the previous code rotated left by five in 16 bits, XOR the current code. Its address is `2048 + ((v ^ (v >> 7)) & 2047)`. Score distinct addresses once per prompt. Use one fixed pass over matched TRAIN instruction pairs. Each present address contributes +1 for a training reference ending in a period and −1 for a bare reference, accumulated as integer counts and stored exactly as little-endian i16. Fail on overflow. Score by adding the weights at visited addresses. A positive score selects period 16, a negative score selects EOS 1, and a zero score takes the ordinary writer proposal.
