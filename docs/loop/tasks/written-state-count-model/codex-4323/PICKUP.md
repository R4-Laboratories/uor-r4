# Separate the two release failures before fitting again

Keep the balanced checkpoint as the integration baseline. Keep the content-link checkpoint as an experimental arm. The latter took scoped held exact replies from 0 to 40/224 pairs, yet erased 75 earlier first-period successes and 32 new direct-count successes. Adding capacity or changing a universal threshold does not identify which release decision needs work. [Report](REPORT.md)

First use a four-arm diagnostic with the same sources and writer on new matched prompts. Compare the fitted path, supplying only the correct first-period action, supplying only the correct post-B action if that boundary is reached, and supplying both actions. Follow each actual emitted prefix. Run both sides of each pair and include direct, quoted and ignored instructions, retaining the prior passing verdicts by pair identity. Report how many first errors disappear at tokens 3 and 4, both sides exact through EOS, and cases where a later choice is never reached. This single test can establish the recoverable gain at each release. In the present held corpus 16 of 56 correctly directed pairs still missed at a later step. The other 168 pairs already missed the first paired flip.

For the next training comparison, use completely matched four-way requests on the **same facts** that vary selector and clause order independently. Include naturally authored direct requests plus a rehearsal set drawn only from earlier TRAIN language. Keep the two existing DEV panels as regression evidence and reserve new families and authors before fitting. Compare joint supervision of first-period and post-B actions with the single-stage content-link model under equal examples and update budget. Require gains on unseen wording types plus retention on both direct and full prior wording controls. Measure the serving cost of the extra link visits before promotion. Once these gates pass, test the ordinary client with source discovery and unsupplied openings on fresh conversations.
