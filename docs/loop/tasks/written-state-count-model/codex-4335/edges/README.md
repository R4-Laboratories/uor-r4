# Replay neighboring native roots on Wick

The probe uses the revision-pinned #4334 cold reconstruction of the two exposed trailing-32 tapes. It uses the #4332 flat trunk and original balanced artifact to replay the current user end, the tail cut, the complete opening and every original candidate occurrence. It compares the product recurrence word against the existing raw-coordinate oracle at each cut. The replay validates the current case's bounds, the fixed-zero query and the paired swapped query. The removed-query arm uses the current case's tail anchor as its query, leaving the corresponding site roots untransported.

For each arm, a bank starts with one transported root. The probe compares its product coordinates with direct signed-axis application through the frozen BFS table and with the pinned additive coordinates. For the edges (0,1), (1,2), (2,3), and (3,0), it applies the canonical D11 action from the left root to zero to the right root. Each bank contains two unit entries among eight axes. The left-zero control holds the left root of every pair at zero, recovering the additive banks in order 1, 2, 3, 0. An inverse rotation of the clamp restores the complete original feature records. The D11 visibility patch applies only to the disposable Wick checkout.

The operator check covers all 256 ordered pairs, preserves raw coordinates, and verifies the first-axis sequence +1, −1, −1, +1 for the pairs (0,0), (0,1), (1,0), and (1,1). This gives a mixed difference of four. The run retains site addresses, frozen offsets and every other field outside the four signed arrays. It repeats extraction in reverse row order and compares every output record after restoring the original order.

On Wick, use absolute paths for the prior cold restores, `EDGES` and each fresh output directory. This builds against the offline Cargo cache.

```sh
bash "$EDGES/run.sh" "$RUNS" "$COLD_4334" "$NEW_FEATURES" "$COLD_4333" "$COLD_4332"
bash "$EDGES/aliases.sh" "$NEW_FEATURES" "$COLD_4333" "$COLD_4332" "$NEW_ALIASES"
```

The main replay consumes the feature and cut tapes, case pairing, the flat trunk and the balanced artifact. The separate alias diagnostic reads the sealed outputs and joins with each panel's truth key by case ID. It counts exact equality on all 32 coordinates, comparing each supported target with every other candidate on its own turn and with targets and rivals on other supported turns. Both alias outputs are aggregate counts. The original feature tapes, reverse outputs, and inverse clamp contain private rows and stay in the private packet.
