## Plain summary

The joint geometric score changed how sites rank, but one 64-byte table still cannot satisfy even the supported questions. The old reader loses the answer at three measurable points. It rejects ordinary matched words before constructing intervals, discards correct value starts whose copies do not meet its completion rule, and can select the wrong assertion from what survives. Supplying an exact endpoint recovers most of the words. The ordinary writer still needs a verified span-release event and a separate decision about what the user wants next.
