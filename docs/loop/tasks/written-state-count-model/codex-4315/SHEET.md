# Shared occurrence scores at the grounded answer opening

[codex] Pre-registration under [#4063](https://github.com/UOR-Foundation/uor-r4/issues/4063). The previous marker-plus-question table often reached a different row but lacked its requested token. At two planted lexical wins the existing geometric writer also emitted a different ID. This unit tests a weight shared across source occurrences and independently measures what that fixed writer can reproduce. Its domain is grounded answers present in the user evidence. The [order](ORDER.md) and [feature contract](product/FEATURES.md) define the model.

**Inputs and state.** Retain the #4314 marker artifact `d782af466c2ebdfba1304158a3f995b50937c434de6ee5a505f8c49cc944f143`, the embedded #4312 answer-first trunk `47214eda18119b1e555cec858f9356c93246a23c9f34686962bc19ba05716049`, the fixed writer and the corrected 118,915-row post-colon donor stream `f490a70c2296e8cc05910f152f36725f2ee132d79a6178e96c826d08de4cdf78`. The new state comprises 512 signed i16 feature weights and one i16 NoRead word, each clipped to ±4,096. Each eligible occurrence contributes one categorical address in each of 16 banks. Its score is the exact i32 sum. Ordinary input IDs, token class and frozen four-block token geometry supply the features. The public learned path receives neither the candidate pair nor an answer ID. Read only on a unique highest-scoring occurrence whose score strictly exceeds NoRead. Pass the exact original ID at that address to the frozen ordinary D11 writer. Ties and insufficient evidence invoke the complete parent.

**Fit.** Use one fixed schedule with zero initial weights. Present the entire corrected tape once in 20 contiguous pieces. Each piece shares a prior-weight snapshot with ten complete four-question TRAIN groups and their ten genuine missing-subject contrasts, ordered by group ID. For each positive controlled row update +6 times the requested feature vector, −4 times the opposite answer vector and −2 on NoRead. Add one requested-vector update and subtract the highest-scoring other eligible occurrence excluding those two, breaking training ties by first position. Skip this additional pair when there is no such competitor. Each of the 200 missing-subject TRAIN rows compares NoRead with the strongest competing source and makes +8/−8 corresponding updates when a source exists. This supplies abstention supervision at the same nominal NoRead dose as the 800 positive rows. Genuine donor openings with a qualifying unique lexical source contribute +1 requested vector and −1 NoRead. Census other donor cases, including ordinary colons, missing and ambiguous sources. Publish the contrast total plus the independently accumulated donor contribution clipped per coordinate to ±128, then clip the combined word to ±4,096. Freeze batch membership, training counts, signed deltas and weight bytes. No held calibration, winner-based sample exclusion or extra fit.

**Held inputs and controls.** Freeze 200 fresh four-way groups. Each crosses an asked person and a value assignment at the same assistant marker, with whole held wording families and held answer IDs disjoint from contrast TRAIN. Verify the actual effective training-ID and wording overlap and the two addresses independently from ordinary text. Grade strict source preference within the supplied answer pair separately from selecting the correct address among all eligible source positions. The learned arm may choose any candidate or NoRead. Run supplied-correct, swapped-source and forced-missing interventions and the frozen marker baseline on the same raw text. Forced missing follows ordinary NoRead. Record both wrong-source and accidental same-emitted-ID cases. Genuine no-answer queries have a separate unforced unsupported-read count. Descriptive transfer includes unseen human passage questions, their real whitespace positions and any missing or ambiguous evidence. Eight prespecified held groups, selected by lexicographically lowest group IDs, additionally receive a single space between facts and question to measure dependence on paragraph formatting. Exclude these variants from the primary 200-group denominator.

**Decision.** The independent unit is a four-question group. Report all-positions registered source wins on both questions within one assignment and all four questions under both assignments. Record first emitted ID, pair preference, source rank among all occurrences and first discrepancy stage. The joint gate is all four correct learned source addresses and all four correct first emitted IDs. Advance to complete replies through EOS if its one-sided 95% exact binomial lower confidence bound exceeds one half (at least 113 of 200 groups). Compare with the supplied-source ceiling under precisely the same writer. Report score/selection vs realization on the oracle-realizable subset, and print the actual counts for learned, correct, swapped, absent and baseline. A source win with a writer alias directs work to writer realization. An accessible gold position lost to a rival despite oracle realization directs work to the source features or fit.
