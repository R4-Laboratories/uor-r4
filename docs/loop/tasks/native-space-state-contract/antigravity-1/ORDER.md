## Five required native-space items (D85 / `.agents/skills/native-space-cycle/SKILL.md`)

1. **Native state schema (`uor-r4.native-state-schema/1`):** Declares all carried fields across three native lanes (`DiscreteSpiralCore`, `WrittenStateCount`, `NativeQ31Vector`): token IDs (`u16`/`u32`), Cl(0,6) codebook blocks (`i32[8]` roots), token cells (`u32 < 256`), route ports (`u32 < 64`), gate trits (`i32` in `-1..=1`), read carry vectors (`i32[8*B]`), discrete trace words (`DISCRETE_ROUTE_TRACE_*`, `DISCRETE_ACTIVE_TRACE_*`, padded relation & pick traces), `ExactCopyState` (`[u32; 4]`) / `ExactCopyStep` (`[u32; 8]`), written-state `S2` packed prime-route keys (`u64`/`u128`), counts (`u32`), `S5` block codes (`u16`), `S6` integer mixer weights/floor, Q31 gate/vector states (`i64[4]` in `-2^31..=2^31`), `Q31HamiltonModel`, `Q31LaneGates`, `NativeQ31Carry`, `Q31FirstPickRead` (`weights`, `gain_shift`, folded `[i64; 16]` addresses, `u32` picks), and `u64` optimizer epochs. Zero float fields.
2. **Shared typed operator paths (`uor-r4.native-operator-registry/1`):** Maps each native transition to verified files and symbols across CUDA training (`discrete.cu`, `native_vector.cu`, `ngram_count.cu`, `kn_score.cu`), integer serving (`discrete_d11.rs`, `discrete_count.rs`, `stack/q31_serving.rs`, `stack/q31_read.rs`), CPU oracle (`uor-r4-cpu-train/src/discrete_route.rs`, `uor-r4-native-vector`, `ngram_count_oracle.rs`, `kn_score.rs`), and WASM (`wasm_serve.rs`).
3. **Transition replay & bit-identical oracle:** `crates/uor-r4-discrete/tests/native_space_state_contract.rs` verifies schema/registry/file-symbol soundness, replays Route, Flock, Pick, ExactCopy, and Q31 (`/12`, `/13`, `/14`) transitions in training vs serving mode comparing raw integer words (`u32`, `i32`, `i64`), and records planted faults F1–F7 failing through the same comparators.
4. **In-state updates:** Discrete legal moves (`discrete_apply` / `CpuDiscreteProposalApplier::apply`), counted S2/S6 integer updates, and Q31 integer L1/margin credit updates (`q31_hamilton_train_step`, `Q31HamiltonModel::step_from_records`, `Q31ReadTrainStep`) update the integer state directly with zero float master.
5. **Lossless serialization:** `UORLUT01` (`lut-discrete/1`, `lut-discrete-trunk/1`, `lut-discrete-count/1`, `lut-stack/12..14`) and fixed-width LE encoders pack raw words without numerical conversion.
