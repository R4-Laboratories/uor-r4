[antigravity] After reviewing the project state, `CHARTER.md` §3.7, `D85`, `docs/harness/native-space.json`, and all six `Done when` criteria of [`docs/roadmap/items/native-space-state-contract.md`](../../../../roadmap/items/native-space-state-contract.md), the top session approves transitioning `native-space-state-contract` from `status: ready` to `status: done` (`done_class: host`) with `Closes #3973`. Logged for Casey, who may reverse it (`CHARTER.md` §5.1, §5.2); no `CHARTER.md` §3 technical constraint or GPU cap is changed.

## Criteria audit (`Done when` #1–#6)

1. **Versioned native-state schema:** `crates/uor-r4-native-vector/src/contract.rs` defines `NATIVE_STATE_SCHEMA_ID = "uor-r4.native-state-schema/1"` (`NativeStateSchemaV1`, `24` carried fields) naming numeric domain, width, scale, admitted range, lifetime, D85 parity field, serialization, and source anchor with zero floating-point domains.
2. **Source-level operator registry:** `contract.rs` defines `NATIVE_OPERATOR_REGISTRY_ID = "uor-r4.native-operator-registry/1"` (`NativeOperatorRegistryV1`, `11` operators) mapping each transition across CUDA training, integer serving, CPU oracle, and WASM; `contract_registry_files_and_symbols_exist_in_workspace` verifies every named file and symbol against the checked-in source.
3. **Finite raw-word replay across all five parity fields:** `crates/uor-r4-discrete/tests/native_space_state_contract.rs` runs deterministic training-vs-serving comparisons comparing raw `u32`, `i32`, and `i64` words across `route choices`, `carry state`, `read choices`, `memory addresses`, and `token ids` over Route, Flock, Pick, ExactCopyState, and Q31 (`/12`, `/13`, `/14`) fixtures (building on existing CUDA legs `cpu_oracle_parity.rs` and `native_vector_cuda.rs`).
4. **Planted faults fail through the shared comparator and are recorded:** Planted faults `F1_operator` through `F7_token` (operator shift, Q31 read gain scale, route port, Flock gate & Q31 gate carry, Q31 1-LSB key read choice & Flock root read choice, corrupted memory cell address, swapped emitted token rows) all fail deterministically and are recorded in [`docs/model/native-space-state-contract.md`](../../../../model/native-space-state-contract.md) and [`REPORT.md`](REPORT.md).
5. **Legacy float/exporter vs native-state boundary documented:** `NativeBoundaryInventoryV1` (`15` classified paths) and [`docs/model/native-space-state-contract.md`](../../../../model/native-space-state-contract.md) explicitly classify `crates/uor-r4-float-train/` and `crates/uor-r4-integer/src/bin/fbs-export.rs` (`lut-stack/1..11`) as legacy/reference code vs the native-default/runtime crates.
6. **Checks pass:** `rustfmt --check`, `cargo test --locked -p uor-r4-native-vector`, `cargo test --locked -p uor-r4-discrete --test native_space_state_contract`, targeted regressions, `wasm32` checks, `clippy` (`--lib -- -D warnings` on `uor-r4-native-vector`, plus `0` warnings in touched files across `--all-targets` and `uor-r4-discrete --test native_space_state_contract`), `uor-harness check --only harness.native_space_contract`, `uor-harness check --staged`, ratchets `d23`/`d25`/`d32`, `uor-harness claim-wording`, `loop report --check`, `loop pr-check --local`, and `xtask links`.
