# Does a shared opening preference hide prompt-dependent scores?

[codex] This supplementary TRAIN-only analysis was specified during physical collection, prior to examining any real score rows. Its inputs are fixed device score words. Grade every unordered pair of distinct articles with different gold coarse cells. For cells A and B subtract the swapped total from the correctly assigned total, using the scores of both cells in each article. Count positive, zero and negative differences and strict wins on both articles. A constant preference for a particular cell contributes exactly zero to the assignment difference. Repeat inside equal gold cells with different gold fine slots, using the two physically captured reference-cell vectors. Fine results condition on reaching the gold cell. Separately report the same calculation for the actually elected cell when both articles admit that cell.

[codex] As a control, cyclically rotate the labels in a fixed SHA-256 ordering of article IDs across every nonzero offset; for conditional fine scoring, rotate only within the relevant gold cell. Report the centered distribution across rotations. Each article participates in multiple comparisons and these articles were used for training. These are descriptive counts, with no nominal independent-pair sample size or test of generalization. Differences in both the question and the passage can contribute. No weights are fitted and no score is sent to the writer. A stronger correct-assignment preference than under rotations motivates a separate held paired test. A weak result directs attention to how the hidden state is trained to encode the requested evidence.
