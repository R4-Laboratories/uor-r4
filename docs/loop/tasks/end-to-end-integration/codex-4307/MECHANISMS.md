# The 27 mechanism families and their jobs

The October board's 12 active, five ready and eleven parked entries are status **rows**. Hopf has two entries with different evidence. Several active entries belong to different model paths. The recommendations below describe how to use the 27 families in a causal experiment. They carry no status promotions. The later trained S0–S6 path and the actual serving source determine what reaches the output today. [Mechanism board](../../../../mechanisms/README.md) · [Stage map](../../../../model/pipeline-map.md) · [Written-state evidence](../../../../research/notebook/m4-serving.md)

| Family | What to carry forward or test |
|---|---|
| Tokenizer | Pin the tokenizer and exact IDs across training, evaluation and serving. Record original UTF-8 bytes for comparable BPB. [Definition](../../../../mechanisms/tokenizer.md) |
| Prime-zeta codebook | Keep exact token identity separate from its geometric address. Compare a trained address against equal-size random and token-context keys. [Definition](../../../../mechanisms/prime-zeta-codebook.md) |
| A8 address cells | A real reduction in vocabulary work requires correct tokens to enter the candidate set. Measure admission before ranking and measure touched bytes. [Definition](../../../../mechanisms/address-cells.md) |
| Route read | Candidate for bounded lookup. Measure route choices, coverage and a disabled or reshuffled route at identical budget. [Definition](../../../../mechanisms/route-read.md) |
| Flock read | Local neighbours can pool meaning. Isolate their contribution with matched zero/random neighbours on held language. M1's composite result cannot assign their individual effect. [Definition](../../../../mechanisms/flock-read.md) |
| Relation read | Candidate for the links between a request and an earlier source. Preserve causal offsets, role swaps and attached values all the way to the token predictor. [Definition](../../../../mechanisms/relation-read.md) |
| Admission | The learned readout can rank only what admission retained. Use full scoring as a measured oracle while testing bounded shortlists and the lawful residual/floor over other words. [Definition](../../../../mechanisms/admission.md) |
| Rank-margin hinge | Useful auxiliary credit for genuine rival occurrences. Keep mixed next-token loss and novel held output as the primary measurements. [Definition](../../../../mechanisms/rank-margin.md) |
| Discrete geometric learning | Primary candidate for actually changing integer weights. Compare proposed coordinate updates to equal-budget random updates; persist the winning state. [Definition](../../../../mechanisms/discrete-learning.md) |
| Hamilton gate | Reuse the discrete trunk's typed rotation and gating path wherever measured. Treat float FBS results as design leads. [Definition](../../../../mechanisms/hamilton-gate.md) |
| SpiralCore/FBS | Transport or structured mixing is a candidate for predictive context at bounded cost. Historical float-master scoring requires a fresh native-state arm. [Definition](../../../../mechanisms/spiralcore-fbs.md) |
| D11 lookup-table serving | Preserve the artifact, exact token identity, versions, integrity and train/serve replay. Compare changes through the ordinary CLI and browser worker. [Definition](../../../../mechanisms/lut-serving.md) |
| Recurrence gates | Candidate for fixed-width carry. Test confusing histories, suffix extension, state restore and whether longer contexts retain task-relevant information. [Definition](../../../../mechanisms/recurrence-gates.md) |
| D19 object store | Provides provenance and durable exact storage. Measure learned write/read address formation, correction, conflict, reset and restart on M3. [Definition](../../../../mechanisms/object-store.md) |
| Hopf observation | Retained fibre is ready for a language test; the sector-only variant is parked. H4, S³ and S² require explicit mappings. Test against randomized routing and measure occupancy. [Definition](../../../../mechanisms/hopf-observation.md) |
| Spin-native weights | Quaternion parameter sharing can reduce stored degrees of freedom. Test native per-token work and learned quality without dense contractions. [Definition](../../../../mechanisms/spin-weights.md) |
| Ternary/XOR | The XOR/popcount descendant is already in the Pick read, a good candidate for Omega cross-backend replay. A dense ternary sweep retains dense work. [Definition](../../../../mechanisms/ternary-xor.md) |
| Carrier credit | The earlier form misassigned credit or relied on a disallowed operator. Reopen on a bounded integer trace only if prediction error reaches the actual addressed cells. [Definition](../../../../mechanisms/carrier-credit.md) |
| Protected legal construction | Preserve proven constraints during local updates. Require improvement on new language as well as protection of historical examples. [Definition](../../../../mechanisms/legal-construction.md) |
| E8 orbit memory | Keep as a keying hypothesis. Run a new scored geometry against equal-byte token and hash controls when it tests a new cause. [Definition](../../../../mechanisms/e8-orbit-memory.md) |
| Exact addressed memory | A supplied address can retrieve the correct fact. Train selection and abstention on text, and compare the ordinary answer against no-memory and bad-address controls. [Definition](../../../../mechanisms/exact-memory.md) |
| Pointer key | Reuse the original-location and copy tests; port only a bounded integer source binding to the ordinary read path. [Definition](../../../../mechanisms/pointer-key.md) |
| Read binding | Use competing referents as TRAIN supervision. Remove labels at inference and verify that the right action or source changes on unseen wording. [Definition](../../../../mechanisms/read-binding.md) |
| VSA | An alternate associative representation. Compare against the stronger causal cache and reseeded hash within the same bytes. [Definition](../../../../mechanisms/vsa.md) |
| Historical geometric stack | Keep its results for understanding carry and readout failures. A port has to train and decode in the same native representation. [Definition](../../../../mechanisms/geometric-stack.md) |
| Historical native geometric engine | Typed facts can score authored questions. Use the recorded transfer collapse as a regression and compare generated natural text before advancing. [Definition](../../../../mechanisms/native-geometric.md) |
| R4G1 graph | The repaired graph infrastructure can aid checking a fixed computation. Compiled teacher preferences or fixture coverage do not supply learned native text weights. [Definition](../../../../mechanisms/r4g1-graph.md) |

The most relevant negative for adding more geometry indiscriminately is P2. E8/Starling and the equal-byte VSA, Hopf, H4 and golden-shell fallback arms each lost against their controls in the configurations evaluated. The most useful positive is the trained P3 mixture's independent improvement over the same causal cache without error-writing. Trainable S1, a token-producing grounded read, and carry-conditioned continuation for words outside the prompt each propose a different way to improve on that result.
