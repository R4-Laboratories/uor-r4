# Compact V3 paired human-source preflight

Use the pinned CoQA v1.0 official TRAIN source as an external held source for compact V3, solely on Wick, through the production literal_roles_v2 real assistant-start boundary. Retain verbatim stories, closed assistant histories and original questions/answers. No model output is an input. Never read sealed D87 DEV-test.

Limit to CoQA Wikipedia, CNN and Gutenberg groups through immutable #4352 custody. Deny all CoQA DEV sources by ID, source filename and normalized complete passage, prior #4352 supplemental sources by the same keys, and historical normalized prompts and selected questions via the parent #4352 D87 bank/preview exclusions. Deny any candidate with an exact 32-token contiguous span of its full prefix/reference stream in the pinned compact V3 train-100m or Gate0 dev-tune or prior-selection chat-v0-p2 streams. This establishes observed exact-sequence overlap exclusion at the declared scale. CoQA does not publish worker or author IDs, so article provenance is the grouping unit. Related prose or paraphrased duplicates can survive the exact screen.

Enumerate turns 2–5 of each full untruncated conversation, preserving at most 2048 prefix IDs. Match the exact original final question and require a common full final question/marker suffix of at least three IDs. Require the first emitted reference ID to equal the first content ID on each side and differ across the pair. Exclude any reference that starts with a standalone space, while keeping complete canonical references through EOS. Require the original answer to be a unique normalized literal substring of its original passage and absent from the other passage. Exclude binary, unknown, and one-character normalized answers. The reference and source check identify an extractive pair. They do not enumerate valid paraphrases or prove how earlier context establishes the referent. Inspect question grounding independently before claiming semantic equivalence across any row. Literal suffix matching does not make layer-specific causal shift histories identical.

Group keys are original source ID, domain and source filename, normalized full passage hash. Greedily choose up to 64 pairs without reusing any group key. Rank exact-question keys by SHA-256 of the domain-separated fixed namespace and raw question, and candidate members by similarly salted original conversation ID and turn number. Keep the pair tape and full provenance private. Freeze before any inference.

The short 512-ID instrument produced two pairs. For the final tape, first select the fixed stratum where both histories fit 512 IDs. Then fill from the stratum where at least one history has 513–2,048 IDs, without reusing any source key. The total cap remains 64 pairs. All controls and semantic filters above apply identically to both strata. The original reference is checked as the exact tail of the complete role-compiled document, and against independent literal assistant-content encoding, the response mask, and single terminal EOS. BOS and EOS inside the reference content are invalid, and all earlier assistant closures must be present.
