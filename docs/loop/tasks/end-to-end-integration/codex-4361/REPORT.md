## Plain summary

[codex] Complete conversation history changed the trained weights and the generated text. Both treatments learned when to end many replies. Neither treatment selected the first piece of the correct answer on a single held conversation. The current bottleneck is getting the evidence in a passage to select a different, correct opening in the deployed model.
